# Mario Lang
The Mario Lang is a transpiled esoteric coding language I developed for my friend Mario.
It is a minimalist programming language that uses a tape of 30,000 memory cells initialized to zero and a single moving pointer. It runs entirely on eight commands that change cell values, move the pointer, handle input/output, or loop based on whether a cell is zero.

## How it works
Mario is similar to the esoteric "BrainF\*ck" created by by Swiss programmer Urban Müller. Unlike BrainF\*ck which uses the characters +, -, >, <, [, ], ( . ) and ( , ) the Mario Lang uses 
- mario 
- mario mario
- mario mario mario
- mario mario mario mario
- mario mario mario mario mario
- mario mario mario mario mario mario
- mario mario mario mario mario mario mario
- mario mario mario mario mario mario mario mario

To separate between the groups of "mario" you can use a double space or a new line.
